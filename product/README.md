# 米奇小杂物收纳盒 v1.2.27

桌面无盖收纳盒，以用户上传照片为外观参考。原参考尺寸为宽220 mm、深205 mm、高300 mm，原盒身高190 mm；按本次底部下凸指示采用默认3 mm下凸量，当前盒身实际高193 mm。已保存的v1.1.0为恢复后的造型；当前v1.2.27以前一版为基础，前侧肚子向前延伸5 mm并连续平滑过渡到上部，删除盒身槽线；盒身底部保持无圆形平面与圆角带的连续曲面，最低点下凸默认3 mm，向周围平滑过渡，使底部更圆润饱满；直径26 mm球饰后移5 mm，隐藏后部按盒身外曲面布尔裁切，保留独立实体并形成无干涉接触；洞口按最新红线重新拟合单段连续圆锥曲线；耳根和腿顶按新盒身重新裁切；洞口按用户标注的侧面红线切割，侧面切口为单段平滑曲线并保持最上沿高度。双耳在上一版基础上再向上4 mm，累计向外4 mm、向上8 mm，外缘圆角保持4 mm；双耳为圆形轮廓，外侧偏上在基础凹面上再向后浅凹约1 mm，背面对应鼓出，前后曲面联动并平滑过渡至外缘。每次修改完成均报告新的当前版本号。保留酒红色圆鼓盒身、黑色大耳朵、前上方圆角敞口、短双腿、黄色饱满圆头鞋面和黑色鞋底以及前方银色球饰。敞口通向连续收纳腔，不增加盖子。壁厚按用户要求增加1.5倍至4.5 mm；内底抬高并与侧壁平滑过渡；双腿与鞋子按最新指示共同后移5 mm，轴线位于Y=5 mm。

## 平台
纯机械收纳产品，无电子板、模块或接线。

## 默认补全
照片只有一个视角，不能确定背面和内部底面。背面按左右对称圆润曲面补全。内底默认抬高20 mm，即盒身局部Z=24 mm（全局Z=124 mm），采用12 mm圆角连接侧壁；洞口沿红线以二次有理Bezier圆锥曲线重建侧面切割边界，向后扩大中段；高度控制112.24 mm，宽度由侧面曲线与盒身相交决定；最高唇边保持全局约281.288 mm，唇边圆角1.2 mm。外底在局部Z=12 mm以下重新构建为圆润曲面，与原盒身匹配位置、一阶及二阶导数，取消底部圆形平面；全局最低Z=97 mm，较上一版下凸3 mm。分色组件按名义接触表达；每只鞋分为黄色上部与黑色下部两个实体，默认采用原槽线下沿Z=8 mm作为分界，鞋底平整。材料以树脂外观效果表达。用于外观设计评审，尚不定义量产工艺和可拆装接头。

## 耳朵造型
双耳采用圆形基础轮廓，默认直径80 mm，前后主体曲面沿Y方向间距12 mm；内部向后凹深默认4.5 mm，外半圈保留基础浅凹；基础过渡控制系数默认0.55。外侧偏上的区域增加默认约1 mm的后凹，左右镜像，向周围平滑衰减；中心和圆形外缘维持基础曲面，边缘圆角4 mm。背面按正面凹陷同步向后凸出，中心鼓出4.5 mm，外半圈和上方偏外侧也同步变化；前后整体包络16.5 mm。圆心全局Z=268 mm、顶部Z=308 mm，安装原点X=±74、Y=5、Z=226 mm。耳根按盒身外曲面布尔裁切，装配后外露轮廓为圆形轮廓的可见部分。直径和浅凹深度为建模默认值，边缘圆角4 mm由用户指定。

双腿与双鞋整体后移5 mm，鞋子建模原点Y=-15 mm，鞋筒局部Y=20 mm，鞋筒与腿轴均为全局Y=5 mm。基础鞋长130 mm，鞋跟向后延长5 mm，总长约135 mm；底轮廓中心Y=-12.5 mm，鞋头前端沿用原位置。底面为前宽后窄胶囊轮廓，鞋头宽98 mm、鞋跟宽92.12 mm；下部黑色鞋底厚8 mm；沿原槽线下沿Z=8 mm与黄色上部贴合，槽线取消，仅保留颜色分界。下沿外周圆角半径4 mm，保留Z=0平底。鞋筒外形58.3×61.6 mm，独立收口51×54 mm。基础收敛系数1.6，鞋头两侧局部系数默认设为1.4，并平滑衰减到鞋跟，让前面两侧更早收拢。鞋跟增加量向脚踝平滑减小。鞋头局部隆起8 mm；鞋筒顶与腿底贴合于Z=84 mm。名义鞋子尺寸98×135×84 mm，采用周期闭合样条截面与连续放样。
