# 米奇小杂物收纳盒 v1.1.0

桌面无盖收纳盒，以用户上传照片为外观参考。原参考尺寸为宽220 mm、深205 mm、高300 mm，盒身高190 mm。当前v1.1.0按用户要求恢复上一版本造型，保留后移鞋型。保留酒红色圆鼓盒身、黑色大耳朵、前上方圆角敞口、短双腿、黄色饱满圆头鞋以及前方银色圆饰。敞口通向连续收纳腔，不增加盖子。壁厚按用户要求增加1.5倍至4.5 mm；内底抬高并与侧壁平滑过渡；双腿轴线必须位于Y=0。

## 平台
纯机械收纳产品，无电子板、模块或接线。

## 默认补全
照片只有一个视角，不能确定背面和内部底面。背面按左右对称圆润曲面补全。内底默认抬高20 mm，即盒身局部Z=24 mm（全局Z=124 mm），采用12 mm圆角连接侧壁；盒口132×122 mm、下沿局部Z=57 mm，唇边圆角1.2 mm。外底恢复上一版轮廓，全局最低Z=100 mm。分色组件按名义接触表达，鞋底平整。材料以树脂外观效果表达。用于外观设计评审，尚不定义量产工艺和可拆装接头。

## 当前鞋型与待确定的尺寸冲突
双鞋身按最新指示向后移动约31.5 mm；鞋身长度从145 mm收短到130 mm，鞋身中心默认Y=-20 mm，鞋口局部Y=20 mm，与双腿全局Y=0对齐。鞋头和鞋跟采用同一连续圆鼓曲面，保留8 mm厚底及细鞋底边线。以上数值为照片比例建模默认值。

当前工作版整体深度约166 mm，与原205 mm尺寸要求不符。后移鞋型已完成供评审，原尺寸要求保持不变；待选择更新深度要求、按205 mm重调鞋型，或将当前鞋型记录为例外。耳朵外移仍有独立宽度待定项：每侧外移8 mm会使整体宽约236 mm，原220 mm宽度要求保持不变。
