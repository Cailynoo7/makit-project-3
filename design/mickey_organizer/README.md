# 米奇桌面收纳盒 v1.1.0

本版按用户要求恢复到盒口缩小、内底再次上移及外底下移之前的造型，保留已经后移并对齐双腿的鞋型。恢复后的CAD源版本与上一版完全相同。原版Git标签v1.0.0保留；当前恢复版使用新版本号v1.1.0。

reference_photo为外形参考。盒身高190 mm，名义壁厚4.5 mm，使用外曲面法向偏置建立内腔。内底局部Z=24 mm、全局Z=124 mm，比初版抬高20 mm，12 mm圆角连接侧壁。盒口132×122 mm、下沿局部Z=57 mm，唇边倒圆1.2 mm。外底恢复全局最低Z=100 mm的上一版轮廓。耳形已圆润并重新布尔裁切。

## Shoes

双鞋身中心Y=-20 mm，鞋长130 mm、宽98 mm，圆鼓鞋身高72 mm。鞋身使用连续放样曲面，鞋头饱满，鞋跟向后呈凸圆轮廓；平底厚8 mm，细边线高0.8、切入0.6 mm。鞋口局部Y=20 mm，与双腿全局Y=0对齐，鞋口顶和腿底均为Z=84 mm。照片未提供侧视图，背部轮廓为对参考比例的建模补全，不能声称与原物所有方向完全一致。

## Pending dimensions

原整体宽220、深205、高300 mm要求保持不变。当前后移鞋型整体深度约166.005 mm，尚待用户选择更新深度要求、按205 mm重调鞋型，或记录当前工作版为例外。原深度要求未满足。耳朵每侧外移8 mm会使宽度约236 mm，外移仍待宽度选择。当前版本保存不代表这些尺寸选择已经解决。

## Connections

所有连接均为free实现，不使用标准件。耳根、双腿和银饰按恢复后的盒身外曲面裁切形成名义接触；不侵入收纳腔。双腿与双鞋口轴线保持Y=0。腿底与鞋口顶面在Z=84 mm接触。每只鞋口与鞋身融合为一个有效实体。无生产接头。

## Making and assembly

本版为外观模型，分色实体不是已验证的生产分件。鞋底在Z=0为平面，适合桌面展示。若进入3D打印设计阶段，需确定材料、拆分与连接结构；盒身顶部及前口弧面可能需要支撑。尚未进行实物打印、承重或抗倾倒测试。无需螺丝，没有可拆接头。双腿移至Y=0属于几何布局改进，不构成实物稳定性验证。
